D1.2 — Consulter les actions réalisées

Cette page permet de consulter les actions réalisées sur votre système dans le cadre de DMP.

Comprendre

DMP peut conserver la trace des actions réalisées afin de permettre leur consultation ultérieure.

Cette information permet de distinguer ce qui a été observé de ce qui a réellement été modifié sur le système.

Une action enregistrée doit être associée à une date et à une description permettant de comprendre ce qui a été effectué.
