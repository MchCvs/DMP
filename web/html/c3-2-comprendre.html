C3.2 — Comprendre les améliorations proposées

Cette page explique les améliorations que DMP peut proposer pour le fonctionnement de votre système Debian.

Comprendre

Une amélioration proposée par DMP doit être liée à un élément réellement observé sur le système.

DMP explique ce qui peut être amélioré, pourquoi cette amélioration est proposée et ce qu'elle peut changer dans le fonctionnement du système.

Une possibilité technique n'est donc pas présentée automatiquement comme une action à effectuer.
