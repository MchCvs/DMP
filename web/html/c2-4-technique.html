C2.4 — Informations techniques

Cette page présente les informations techniques utilisées par DMP pour analyser les possibilités de nettoyage.

À quoi servent ces informations ?

DMP utilise les informations techniques pour identifier les éléments pouvant éventuellement être nettoyés, mesurer leur taille et évaluer le bénéfice possible.

Ces informations permettent de distinguer une possibilité de nettoyage d'une recommandation réellement utile.
