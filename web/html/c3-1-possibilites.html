C3.1 — Identifier les possibilités d'amélioration

Cette page permet d'identifier les éléments du système pour lesquels une amélioration peut être envisagée.

Comprendre

Une optimisation consiste à améliorer un fonctionnement existant sans modifier inutilement le système.

DMP commence par observer le fonctionnement actuel afin d'identifier les possibilités d'amélioration réellement pertinentes.

Une optimisation n'est pas proposée uniquement parce qu'une modification est techniquement possible.
