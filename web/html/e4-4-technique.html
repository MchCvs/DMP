E4.4 — Informations techniques

Cette page présente les informations techniques relatives à la préparation des données destinées aux graphiques DMP.

À quoi servent ces informations ?

Les informations techniques permettent de suivre le traitement des données avant leur représentation.

Elles permettent notamment de distinguer les données disponibles, vérifiées et réellement exploitables.
