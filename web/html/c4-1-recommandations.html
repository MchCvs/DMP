C4.1 — Voir les recommandations

Cette page présente les recommandations que DMP peut formuler à partir des observations réalisées sur votre système.

Comprendre

Une recommandation DMP est liée à une observation réalisée sur le système.

Elle indique une action qui peut être envisagée, sans la présenter automatiquement comme nécessaire.

DMP distingue donc clairement ce qui est observé, ce qui est expliqué et ce qui est recommandé.

Informations complémentaires

Recommandation

Aucune recommandation disponible

DMP ne dispose actuellement d'aucune recommandation issue d'une observation suffisamment établie.

État

Aucune action recommandée

Aucune action n'est proposée tant qu'une observation ne justifie pas une recommandation.

Informations techniques complémentaires

Ces informations sont utilisées automatiquement par DMP. Elles ne sont pas à exécuter ici.
