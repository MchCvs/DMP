# 4. Principes appliqués

Le développement DMP respecte les principes suivants :

- comprendre avant d'agir ;
- sauvegarder avant modification ;
- vérifier avant validation ;
- documenter les évolutions ;
- conserver un historique clair.

DMP applique à son propre développement les principes qu'il souhaite transmettre à ses utilisateurs.


---

# 5. État actuel du projet

Le projet DMP 1.7.0 dispose maintenant :

- d'une base de développement active identifiée ;
- d'une organisation documentaire claire ;
- d'une méthode de développement définie ;
- d'un historique conservé ;
- de points de restauration disponibles.

La version 1.7.0 constitue une base stable pour les futures évolutions.

---

# 6. Prochaines évolutions

Les prochaines évolutions devront respecter la méthode DMP :

1. observer l'état existant ;
2. comprendre l'objectif ;
3. sauvegarder avant modification ;
4. préparer une évolution contrôlée ;
5. vérifier les résultats ;
6. documenter la modification ;
7. intégrer uniquement après validation.
