# 1. Rôle du document

Ce document constitue la porte d'entrée de la documentation du projet DMP.

Son objectif est de permettre à toute personne découvrant le projet de comprendre :

- par où commencer ;
- quel document consulter selon son besoin ;
- comment les différentes parties du projet sont organisées.

La documentation DMP n'est pas seulement une collection de fichiers.

Elle constitue un parcours de compréhension du projet.

---

# 2. Parcours de découverte DMP

Un nouveau lecteur peut suivre ce chemin :


# 4. Documents fondamentaux

Les documents suivants constituent la base de compréhension du projet DMP.

Ils sont présentés selon un parcours logique de découverte.

---

## 4.1 Comprendre l'organisation du projet

### README_STRUCTURE_DMP.md

Présente l'organisation générale des dossiers DMP et le rôle de chaque espace du projet.

### ARCHITECTURE_DMP.md

Présente l'architecture générale du projet DMP et explique l'organisation des différents espaces du projet.

Ce document constitue une référence de compréhension globale de la structure DMP.

---

## 4.2 Comprendre la méthode de développement

### METHODE_DE_DEVELOPPEMENT_DMP.md

Présente la méthode utilisée pour faire évoluer DMP de manière contrôlée et reproductible.

### DEVELOPPEMENT_DMP.md

Définit les principes de développement, les règles de modification et les exigences de qualité du projet.

---

## 4.3 Comprendre les principes de dialogue DMP

### CONCEPTION_DIALOGUE_TECHNIQUE_DMP.md

Présente les principes de conception du dialogue technique DMP.

Ce document explique :

- la philosophie d'accompagnement de l'utilisateur ;
- la séparation Action / Observation / Compréhension ;
- la règle anti-confusion documentaire ;
- les principes de vérification et de validation.

Il constitue la référence pour comprendre comment DMP présente les opérations techniques et accompagne l'utilisateur vers l'autonomie.

# 8. Utilisation de cet index

Cet index constitue le point d'entrée principal de la documentation DMP.

Il doit permettre à chaque utilisateur ou contributeur de trouver rapidement le document adapté à son besoin.

Lorsqu'un nouveau document important est créé dans le projet, son rôle doit être ajouté à cet index afin de conserver une documentation cohérente.

La documentation DMP évolue avec le projet tout en conservant une organisation claire et compréhensible.
